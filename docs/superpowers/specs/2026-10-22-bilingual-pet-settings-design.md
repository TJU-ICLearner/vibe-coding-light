# Vibe Coding Light 中英文切换与桌宠设置页整理

日期：2026-10-22  
状态：待用户审阅

## 目标与范围

用户可从菜单栏图标的菜单中选择“中文”或“English”。所选语言立即作用于应用提供的菜单、托盘状态提示、窗口标题、桌宠设置页及已知操作错误，并在重启后保留。选择 English 时，应用自身的交互文案全部为英文。用户填写的宠物名称、文件名、命令、路径及 Agent 传入的自由文本保留原文；macOS 或第三方库生成的底层错误详情也可能保留系统语言。

设置页在“按状态”模式下保留默认素材预览的位置，清楚区分默认／休息、工作、等待、出错、完成五个素材位。页面沿用当前轻量、安静的产品气质，改善层级、间距、焦点和空状态。单图模式及已保存桌宠的文件格式和行为保持兼容。

## 已确认的交互

1. 菜单增加“语言 / Language”分组，显示互斥的“中文”和“English”选项，并标记当前选项。切换无需重启；菜单文字、显示／隐藏桌宠、钩子安装结果、状态提示和已打开的设置窗口同步刷新。
2. 首次启动且没有用户偏好时，根据操作系统首选语言选择中文或英文；只有 `zh` 语言族使用中文，其余语言使用英文。用户显式选择后以保存的值为准。无法读取或损坏的偏好文件按系统语言回退，不阻止应用启动。
3. 设置页语言跟随全局选择，不另设独立开关。页面标题、说明、标签、占位符、按钮、状态名、导入模式、空状态、警告、验证错误、保存／删除反馈和图片 `alt` 文本均使用当前语言。切换语言不丢失尚未保存的草稿，也不改变当前桌宠。
4. 单图模式只显示默认素材编辑区。按状态模式显示一行五个明确分隔的素材标签：“默认／休息、工作、等待、出错、完成”。一次编辑一个素材位；切换标签保留各自的文件、处理方式和预览。默认素材为必选，其他四项显示“未设置则使用默认素材”的提示。`unknown` 继续使用默认素材，不增加第六个上传位。
5. 右侧预览区在可用宽度下保持可见，展示当前标签的原图与 128×128 桌宠效果；页面滚动时预览区保持在视野内。窄窗口改为上下布局，预览排在素材编辑区前。选择“按状态”不再把默认素材预览推到四张状态卡片之后。大小、位置和状态预览共用当前素材，不重复显示第二组含义相同的状态按钮。

## 视觉设计

保留白色卡片和绿色主操作色，使用更明确的浅灰绿色页面背景、较少但一致的边框与阴影。页面分为简洁标题、制作方式、素材编辑与预览、大小位置、已保存桌宠四层；标题和简短说明引导首次使用。五个标签具有相同尺寸、边框与间距，当前标签使用高对比边框和底色，并显示“已设置／使用默认”文字标记；颜色只是辅助，不能单独承担状态含义。预览卡使用棋盘格表示透明，明确标注“原图”和“桌宠效果”，没有素材时提供有用的空状态。错误在所属素材位附近显示，保存按钮附近只显示影响保存的汇总错误。所有可操作项有键盘焦点样式；英语长文案在最小 620px 窗宽及放大字体时可以换行，不遮挡按钮。

## 架构与数据流

- Rust 持有全局 `AppLocale`（`zh-CN` / `en`），在应用数据目录以小型偏好文件持久化。保存采用临时文件加原子替换，避免中断后留下半写文件。新增读取和设置语言的 Tauri 命令；设置成功后发出 `locale-changed` 事件。
- Rust 的菜单和托盘提示只从同一套语言资源取文案。切换时原位更新菜单项和 tooltip，保留桌宠可见状态与钩子安装反馈状态。设置窗口标题随语言更新。
- 前端以键值化的双语资源渲染设置页静态与动态文案。启动时读取 Rust 当前语言，之后订阅 `locale-changed`；窗口打开期间切换会即时重绘文案，不重新挂载草稿控制器。文件校验与可预期的后端错误映射为稳定错误类别再翻译，不以某种语言的错误句子作为业务判断条件。
- 素材草稿仍由现有 `AssetDraft` 按五个固定位置管理。界面只改变当前可见编辑区和预览区，保存仍使用已选模式的完整素材集合；单图模式仍只保存默认素材。状态渲染、GIF 播放、旧版宠物包读取与钩子事件语义不变。

## 等待状态的说明

界面帮助文案简短说明“等待”代表需要用户确认或交互输入：Claude Code 的权限／交互通知及 Codex 的 `PermissionRequest` 会触发；普通无需审批的工作可直接从“工作”进入“完成”。这是现有钩子的真实行为，本次不改变状态判定或新增推测式等待。

## 错误与边界

- 保存语言失败时仍保持旧语言并在菜单操作日志中记录错误；不要出现菜单与设置窗口语言不一致的状态。设置窗口暂时不可用时，重开后从 Rust 读取正确语言。
- 已上传图片的解析、抠图、GIF 校验和保存失败仍阻止错误内容入库。双语提示保留当前具体限制（如 10 MiB、透明 GIF、允许的尺寸范围）；未知系统错误使用本地化前缀并保留原始技术详情。
- 切换语言、切换素材标签或制作方式不会触发文件重新处理，也不会修改已选桌宠。删除、保存和钩子安装仍需原有成功结果后才更新界面状态。

## 验收与验证

1. 中文和英文两种设置下检查完整菜单、托盘状态、窗口标题、设置页初始／处理中／成功／失败／缺图状态；英文模式无内置中文文案。语言选择跨重启保留，损坏的偏好文件安全回退。
2. 在已打开设置窗口中切换语言，草稿、当前素材位、大小位置和已选桌宠不变；菜单与窗口同步更新。
3. 切到按状态模式后，默认素材预览保持在首屏可见，不会落在四个可选素材之后；五个标签有明确选中状态，各自的图片与导入模式互不覆盖，缺省项预览回退默认素材。单图模式仅保存默认素材。
4. 前端测试覆盖双语资源、即时切换、五素材位切换与保存范围；Rust 测试覆盖偏好读取／保存回退、菜单和状态文本。macOS 打包实测中文／英文切换、设置窗口布局与重启；至少在 760×760 和 620×540 窗口下做视觉检查。
5. 发布前运行前端和 Rust 全套测试、构建 DMG，并对 DMG 中的 `.app` 执行严格代码签名校验，避免再次发布“已损坏”的安装包。

## 本次不包含

不新增状态事件源，不改变“等待”的触发条件；不翻译用户输入、Agent 自由文本或系统底层错误详情；不增加第三种语言，不改宠物包格式，不引入云端翻译或图片处理服务。
