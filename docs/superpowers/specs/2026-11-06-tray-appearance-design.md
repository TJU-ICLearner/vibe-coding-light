# 菜单栏统一入口与外观主题设计

## 目标

macOS 菜单栏图标左右键打开同一个可停留的快捷控制弹窗。弹窗采用已确认的“概览 / Agent 接入 / 设置”三页布局，减少重复信息，并提供可持久化的外观设置。桌宠设置与通知设置窗口使用同一外观；桌宠图片、GIF 与透明宠物窗口不改色。

## 外观规则

- 首次安装及旧版本迁移默认“跟随系统”。系统浅色使用已确认的 A 配色；系统深色使用所参考的“夜雨”配色。
- 关闭“跟随系统”后，可固定选择六种主题：**系统浅色、系统深色、社戏、晨雾、知秋、芭蕉**。短名分别来自原主题“社戏 / 晨雾 / 一叶知秋 / 雨打芭蕉”；“夜雨”只作为系统深色的来源，不再重复列为手动主题。
- 系统外观变化、手动切换、应用重启和打开新设置窗口都立即呈现正确主题。中文和英文界面同步更新主题名称与提示。
- 主题状态与语言一样保存到应用数据目录。参考配色只移植到应用界面所需的少量颜色令牌，并在源码与文档标注原作者及 MIT 许可。小字号文字可作对比度调整。

## 菜单与内容

- macOS 左右键均切换同一个弹窗；再次点击、点弹窗外或按 Esc 收起。Windows 和 Linux 维持原生托盘菜单，并增加外观子菜单。
- “概览”顶部显示最近一个会话的来源、项目和状态，下面的其他近期会话不重复此项；桌宠显示、摸摸、自定义桌宠和 Bark 状态保持一眼可见。
- “Agent 接入”集中展示六个来源的 Hook 状态与通知开关状态，保留安装或更新动作。DeepSeek Harness 的“准备桥接”状态不能误写成完全安装。
- “设置”包含通知设置、桌宠设置、语言、登录时启动、自动检查与检查新版本、外观设置、退出。常规开关操作后弹窗继续显示。
- 菜单上展示的 Bark 状态取自通知服务的真实状态；无密钥、服务不可用和发送失败不得显示“已连接”。

## 方案与取舍

1. **保留两套 macOS 菜单：** 实现最省，但用户已遇到左右键内容重复和不同步。
2. **左右键共用弹窗（已选）：** 单一入口、可连续操作；需要为 macOS 去掉自动弹出的原生菜单，并为其他平台保留原生菜单。
3. **引入完整设置窗口导航：** 空间足，但常用操作会增加点击。

主题采用显式六种令牌与“跟随系统”偏好，避免复制完整编辑器主题 JSON。相较导入任意外部主题，这便于控制对比度、双语标签和各窗口一致性。

## 验收

- macOS 左右键打开同一弹窗，重复点击、点击外部、Esc 正常收起；拖动桌宠及全屏置顶不受影响。
- 六种主题与跟随系统行为正确，重启后保留选择；独立打开桌宠设置和通知设置仍一致。
- Agent 安装状态、通知开关、Bark 状态与实际设置一致；切换语言后全界面标签一致。
- Windows/Linux 原生托盘菜单仍可操作并能选外观。
