# BoardUI Pet Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a functional BoardUI-based desktop pet settings window with unchanged pet data and preview behavior.

**Architecture:** Add React 19, Tailwind CSS v4, and committed free BoardUI source to the existing Vite app. Keep Tauri commands and pet operations in a headless model; React owns the settings page DOM. Introduce a theme adapter reused by the notification and tray plans.

**Tech Stack:** Tauri 2, Vite 6, TypeScript, React 19, Tailwind CSS v4, BoardUI free components, React Aria, Vitest, jsdom.

**Spec:** `docs/superpowers/specs/2026-11-21-boardui-interface-design.md`

## Global Constraints

- Six persisted theme IDs stay `system_light`, `system_dark`, `shaxi`, `chenwu`, `zhiqiu`, `bajiao`; follow-system behavior stays compatible.
- Chinese and English UI must stay complete. No remote font or Pro component is required.
- `index.html` and the transparent pet renderer must not import BoardUI or Tailwind global styles.
- Existing Tauri commands, pet manifests, built-in pets, GIF playback, 0.5–3.0 scale, and partial-save behavior remain unchanged.
- Preserve `docs/previews/` and the stable release; publish only a prerelease after all three plans and platform checks.

## Review Focus

- A GIF selected for a state still animates in preview after switching to another state and back; test in Task 2.
- Selecting either built-in pet then changing state updates the visible preview without changing the selected pet; test in Task 2.
- A save that succeeded on disk but failed to select cannot be retried into a duplicate; test in Task 2.
- Loading a new image while an older background-removal request is pending displays only the newest result; test in Task 2.
- A narrow 620 px window leaves preview and Save reachable without horizontal scroll; verify in a browser layout smoke check in Task 2.

## File map

- `package.json`, `pnpm-lock.yaml`, `vite.config.ts`, `tsconfig.json`, `boardui.json`: React/Tailwind/BoardUI configuration and stable local paths.
- `src/ui/boardui/**`, `src/ui/BOARDUI-SOURCE.md`: committed free component and utility source generated by BoardUI CLI, with exact CLI version, upstream links, and retained license notices.
- `src/ui/boardui.css`, `src/ui/boardui-theme.css`: Tailwind entry and semantic palette bridge, loaded only by settings/notifications/tray.
- `src/appearance.ts`, `src/appearance.test.ts`: persisted theme resolution and `.dark` compatibility.
- `src/pet-settings/model.ts`: exported `SettingsController`, `PreviewController`, `SettingsApi`, and pet draft operations moved from `src/settings.ts` without changing command payloads.
- `src/pet-settings/PetSettingsPage.tsx`, `src/pet-settings/PetSettingsPage.css`: BoardUI page and responsive layout.
- `src/settings.ts`, `settings.html`: React bootstrap, locale/theme event binding, and one root element.
- `src/pet-settings/PetSettingsPage.test.tsx`, `src/settings.test.ts`: user-visible interaction and operation regression tests.
