# Vibe Coding Light v1.1.1

修复 v1.1.0 在其他 Mac 上可能显示“已损坏，无法打开”的安装问题。macOS 安装包现在对完整 `.app` 使用 ad-hoc 签名，而不再只保留可执行文件的链接器签名。

功能与 v1.1.0 相同：支持单图和按工作状态分别设置图片，并可导入已有透明背景的 GIF；旧版桌宠仍可读取。

适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”。本版尚未使用 Apple Developer ID 签名或公证；首次打开如被 macOS 拦截，可前往“系统设置 → 隐私与安全性”点击“仍要打开”。如果仍出现“已损坏”提示，请先核对同页 `SHA256SUMS.txt`，再按 [中文安装说明](https://github.com/TJU-ICLearner/vibe-coding-light/blob/main/README_CN.md#macos-提示已损坏或无法打开) 处理。Intel Mac 暂无预编译安装包。

构建时已校验 DMG 内应用的代码签名。macOS 12–13 及其他 Apple 机器的实际交互仍待测试。
