# Vibe Coding Light v1.5.0 RC3

修复 Bark 设备密钥输入校验。先前输入测试链接中“密钥 + `/title/body?...`”时，应用会将整段误存为密钥，直到发测试通知才显示 Bark 拒绝请求。现在保存时直接阻止带路径、查询参数、空格或完整 URL 的输入，并说明设备密钥位于测试链接的域名后、下一个 `/` 前。旧版已保存的错误格式也会在发送测试通知时给出明确提示。

适用于 Apple Silicon Mac（macOS 12 或更新版本）。安装包使用 ad-hoc 签名，未经过 Apple Developer ID 公证；请参照 README_CN.md 中的 macOS 安装说明。Bark 请求仍发往官方 `api.day.app` 服务。
