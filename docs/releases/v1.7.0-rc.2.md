# Vibe Coding Light v1.7.0 RC2

本版修复 RC1 的菜单栏体验：

1. “每天检查新版本”更名为“自动检查新版本”。自动检查仍默认关闭，开启后最多每 24 小时检查一次。
2. 手动检查新版本时，GitHub API 请求失败会自动尝试 GitHub 发布订阅源。检查成功且没有新版本时，菜单显示可点击的“当前已是最新版本 · 点击重新检查”。
3. macOS 返回“未找到登录项”时，“登录时启动”不再置灰；应用会尝试为已安装在“应用程序”中的 App 创建当前用户的登录启动项。系统原生登录项仍优先使用。

请在 Mac 上重点验证：手动检查新版本、开启和关闭登录启动，并注销后重新登录确认是否自动启动。若要启用登录启动，请先把 App 拖入“应用程序”文件夹。

安装包为 Apple Silicon 版 ad-hoc 签名测试包，未经过 Apple Developer ID 公证。
