# Vibe Coding Light v1.6.0 RC2

此测试版修复桌宠进入其他应用的 macOS 原生全屏空间后消失的问题。桌宠窗口改为非激活面板，配置跨应用全屏显示和全屏之上的窗口层级；菜单栏重新显示桌宠时不会主动切换离开当前全屏应用。拖动或缩放桌宠时会留出菜单栏空间；打开本应用菜单时，桌宠会暂时降到菜单下方。通知模板与详细内容开关延续 RC1。

请在 macOS 上测试：

1. 在普通桌面拖动桌宠、点击“摸摸”、隐藏后重新显示，确认交互仍正常。
2. 用绿色全屏按钮让 Safari、终端或编辑器进入原生全屏，再切换到该全屏空间，确认桌宠仍在前方，点击桌宠不会退出全屏。
3. 将桌宠放在菜单栏下方，展开本应用菜单，确认菜单选项可以点击；从全屏空间打开桌宠设置和通知设置，确认窗口能正常使用。
4. 使用 Retina 或双屏 Mac 时拖动桌宠、切换或放大桌宠，确认位置连续且不会盖住菜单栏；退出全屏后桌宠仍可见。

跨应用全屏标志需要 macOS 13 或更新版本；旧版 macOS 只使用系统支持的辅助全屏窗口标志。如果把桌宠放在其他应用的下拉菜单正下方，它仍可能遮住该应用的菜单项；请将桌宠拖离菜单区域并反馈具体应用。此版仍是 ad-hoc 签名测试包，未经过 Apple 公证。
