# Vibe Coding Light v1.5.0

新增可选 Bark 通知。可以分别选择 Claude Code、Codex 的权限确认、提问、本轮完成、错误，以及剩余 80%、50%、20%、0% 和额度恢复提醒；额度通知标明来源与周期。通知默认关闭，只在应用运行且总开关开启时发送所选事件，不包含提示词、项目路径、命令或错误原文。

在菜单栏的“通知设置”中，保存 Bark 测试链接中域名后、下一个 `/` 前的**设备密钥**，不要粘贴完整链接或其余路径；当前连接官方 `api.day.app` 服务。设置页支持中文和英文。测试按钮会就近显示发送状态及错误原因，错误格式会在保存时被拦下。原有桌宠、自定义素材和已安装的 Hook 可以继续使用。

此版已通过自动测试、本机安装包与签名校验；用户实测确认 Bark 测试通知送达 iPhone。Apple Watch 是否显示通知取决于 Apple 的路由设置，仍建议在目标设备上核对。部分 Codex 界面内提问没有可观察 Hook；Claude/Codex 额度接口也可能因版本或登录方式不可用，设置页会显示可用状态。

适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”。本包使用 ad-hoc 签名，**没有 Apple Developer ID 公证**；若 macOS 阻止打开，请按[中文安装说明](https://github.com/TJU-ICLearner/vibe-coding-light/blob/main/README_CN.md#macos-提示已损坏或无法打开)核对校验和并处理。Intel Mac 暂无预编译安装包。
