# Vibe Coding Light 1.0.3 RC2

候选测试版，包含 RC1 的修复。正式版仍为 1.0.2；请完成实机验证后再决定正式发布。

## 本轮改动

- 保存、切换或删除桌宠成功后，即使后续列表或预览刷新失败，也会准确显示操作已成功，并提供重新载入入口。保存成功的草稿不会因为刷新失败而被再次保存成副本。
- 若桌宠素材已写入磁盘但设为当前桌宠失败，会显示“已保存、未选中”，同一份草稿不会重复保存。
- 通知设置中，Bark/Hook 状态或诊断记录读取失败不会阻止其余设置加载；失败部分会标为未知并提供重试，不会把未知密钥状态误写成“尚未保存”。
- 更新检查会根据发布日期排除已移除的旧测试版，并在升级后清理旧缓存、重新检查；正式版复用的标签仍可被识别。稳定版不会显示缓存中的 RC。

## 实机检查

1. **macOS、Windows、Linux**：升级 RC1 到 RC2，确认桌宠、托盘、已有通知和主题设置仍正常。
2. **桌宠**：保存新桌宠后只出现一个副本；切换默认布布、一二和自定义桌宠；取消、确认删除；桌宠仍可拖动。
3. **通知**：打开通知设置，确认 Bark 密钥和开关仍在，通知文案仍在；检查真实事件通知。不要在反馈中发送设备密钥。
4. **版本检查**：在 RC2 点击检查新版本，不应再出现已删除的旧测试版标签。
5. **Windows、Linux**：重复启动程序时仍只保留一个实例。

## English

This prerelease includes RC1's fixes. Stable 1.0.2 remains current pending device validation.

- Successful pet saves, selections, and deletions remain successful when a later list or preview refresh fails. A retry control refreshes the stale view; a saved draft cannot be saved again by accident.
- If a pet is saved but selection fails, the UI reports that partial outcome and prevents a duplicate save from the same draft.
- Notification settings remain editable if Bark/Hook status or diagnostics cannot load. Unknown status is labeled as unknown and can be retried.
- Old test releases are excluded by publish date. Upgrades clear the old update cache and check again, while newly reused tags remain eligible. Stable builds do not offer cached RC releases.

On macOS, Windows, and Linux, test upgrade, pet selection and dragging, Bark settings and real events, version checks, and repeated launches on Windows/Linux. Do not include a Bark key in feedback.
