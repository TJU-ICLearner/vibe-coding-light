# Vibe Coding Light v1.7.0 RC6

额度提醒增加独立的“7 天额度剩余 0%”开关和测试按钮，适用于 Claude Code 与 Codex 的周额度。原有“剩余 0%”改为其他周期；升级时，旧设置中已开启的 0% 提醒会同时开启两个新开关，保持原有提醒范围。周额度通知仍标明来源和周期；首次读到已耗尽的额度只建立基线，不补发过去未观察到的变化。

免打扰时段内，所有测试消息都会显示“未发送：免打扰时段”，包括 Bark 连接测试，以及允许真实事件绕过免打扰的类别。真实事件仍按“以下通知仍然发送”中的例外设置处理。测试跳过会记录到本机诊断列表。

实机检查：在免打扰时段内分别点击 Bark 连接测试和任一事件测试，确认两处显示跳过且手机不收到测试消息；在时段外测试“7 天额度剩余 0%”，确认通知写明 7 天周期。真实周额度到 0% 的提醒需在实际跨过阈值时验证。
