# Vibe Coding Light v1.7.0 RC5

macOS 菜单栏图标左键现在打开可停留的快捷控制弹窗。连续切换“登录时启动”“自动检查新版本”和语言，或手动“检查新版本”时，弹窗不会自动收起，检查进度与结果会在原位更新。再次点击图标、点击弹窗外或按 Esc 可收起。右键仍保留原有原生菜单。

弹窗保留桌宠、通知设置、Hook 设置、当前会话、版本下载和退出入口。打开其他设置窗口或下载页时会收起；当前会话保持只读。支持中英文界面，并将弹窗限制在菜单栏图标所在屏幕的可见区域。

这是 Apple Silicon 版 ad-hoc 签名测试包，未经过 Apple Developer ID 公证。请在 Mac 上重点检查连续操作、不同屏幕的弹窗位置，以及全屏空间中的显示与收起行为。
