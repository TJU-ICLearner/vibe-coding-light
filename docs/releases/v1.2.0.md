# Vibe Coding Light v1.2.0

菜单栏现可在**中文／英文**之间切换。菜单、状态提示、设置窗口标题、桌宠设置页和图片导入错误随之即时切换，选择在重启后保留。首次启动按系统语言选择，中文系统默认中文，其余默认英文。

桌宠设置页改为五个分明的素材标签：默认／休息、工作、等待、出错、完成。一次编辑一个素材，预览在宽窗口位于编辑区旁，在窄窗口排在编辑区前。切换语言、标签或单图／按状态模式会保留尚未保存的草稿；未设置的状态沿用默认素材。继续支持透明 GIF 与旧版单图桌宠。

“等待”由 Claude Code 的权限／交互通知或 Codex `PermissionRequest` 触发；无需审批的任务可从工作直接到完成，然后回到休息。这一版没有新增通用的“等待用户回复”检测。

适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”。安装包仍使用完整应用 ad-hoc 签名，尚未经过 Apple Developer ID 公证；首次启动如被 macOS 拦截，请参见 [中文安装说明](https://github.com/TJU-ICLearner/vibe-coding-light/blob/main/README_CN.md#macos-提示已损坏或无法打开)。Intel Mac 暂无预编译安装包。

发布前验证：前端、Rust 测试与构建通过；原生 macOS WebView 在 760×760 和 620×540 下检查中英文与五状态布局；DMG 内应用须通过严格签名检查。macOS 12–13 和其他 Apple 机器的实际交互仍待用户测试。
