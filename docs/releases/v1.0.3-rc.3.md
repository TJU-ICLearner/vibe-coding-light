# Vibe Coding Light 1.0.3 RC3

界面候选版。正式版仍为 1.0.2；请完成实机验证后再决定正式发布。

## 改动

- 桌宠设置、通知设置与快捷控制逐页接入 BoardUI 免费组件，保留现有六种主题和中英文界面。
- 桌宠设置保留单图及五状态素材、默认布布／一二 GIF 预览、静态图片动效、保存草稿防重复、失败重试与具名删除确认。
- 通知设置将 Bark 密钥、来源 Hook、事件、额度、免打扰、通知文案和诊断记录整理到统一分区。Bark 状态读取失败时，其余设置仍可操作；输入中的密钥及模板草稿不会因状态刷新丢失。
- 快捷控制统一为三个标签页。连续切换开关、检查新版本时面板保持打开；每秒刷新不会替换正在操作的语言控件。
- 桌宠悬浮窗口、Tauri 命令、通知设置格式与现有主题标识保持兼容。

## 安装后请检查

1. **macOS、Windows、Linux**：打开三个界面，检查中文与英文、六种主题；在窄窗口确认预览、保存按钮和通知开关可见。
2. **桌宠**：切换单图／五状态和默认布布／一二；预览 GIF，导入图片并保存；确认删除弹窗；检查桌宠拖动与全屏置顶。
3. **通知**：确认 Bark 密钥仍显示为已保存；修改来源、额度和免打扰；编辑通知文案并重开窗口确认保存。不要在反馈中发送设备密钥。
4. **快捷控制**：连续切换登录启动、自动检查更新和主题；检查菜单不提前收起、语言选择不跳动、Escape 可关闭。
5. **Windows、Linux**：重复启动程序时仍只有一个实例。

## English

This is a prerelease for device testing. Stable 1.0.2 remains current.

- Desktop pet settings, notification settings, and quick controls now use free BoardUI components while preserving the six themes and both interface languages.
- Pet settings retain single-image and five-state assets, built-in GIF previews, static-image motion, duplicate-save protection, retry states, and named delete confirmation.
- Notification settings group Bark connection, Hooks, events, quotas, quiet hours, message templates, and diagnostics. A failed status read does not block settings. In-progress key and template input survives refreshes.
- Quick controls use three tabs. Toggles and update checks keep the panel open; polling preserves the active language control.
- The floating pet, Tauri command names, saved settings, and theme identifiers remain compatible.

After installing on macOS, Windows, or Linux, check both languages, six themes, narrow layouts, GIF preview, pet dragging, Bark settings, template recovery, quick-control focus, and single-instance behavior on Windows/Linux. Do not include a Bark key in feedback.
