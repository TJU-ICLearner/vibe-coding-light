# Vibe Coding Light v1.1.0

本版支持用**一张图片**或**按工作状态分别设置图片**制作桌宠。按状态模式可为工作、等待、出错、完成状态添加素材；未设置时使用默认素材。切换制作方式会保留当前草稿，单图模式只保存默认素材。

每个位置可上传 PNG、JPEG 或已有透明背景的 GIF。静态图继续支持 macOS 14+ 的本地自动去背景；透明 PNG 和透明 GIF 可在 macOS 12–13 导入。GIF 保留原有帧时序，不进行逐帧抠图；损坏、不透明或超限的 GIF 会被拒绝。旧版单图桌宠继续可用，无须迁移。

适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”。安装包未经过 Apple 开发者签名和公证；若被 macOS 阻止打开，请在 Finder 中右键点击应用并选择“打开”。Intel Mac 暂无预编译安装包。

构建时已通过前端、Rust 测试和 DMG 校验。在 macOS 26 的独立测试实例中，已验证单图 GIF 逐帧播放、JPEG 自动抠图、按状态保存、重启后读取旧版桌宠、缺失工作素材回退以及内置像素猫切换。macOS 12–13 和其他 Apple 机器的实际交互、GIF 循环与状态重新进入时的播放行为仍待测试。安装包的 SHA-256 摘要见同页的 `SHA256SUMS.txt`。
