# Vibe Coding Light 1.0.3 RC1

候选测试版。请先在自己的设备上验证，再决定是否发布为正式版。当前正式版仍为 1.0.2。

## 本轮改动

- 通知文案的待保存草稿会临时留在本机，应用意外退出后重新打开通知设置会恢复并重试保存；保存成功后清理临时草稿。不会在这里保存 Bark 密钥。
- Hook 安装和 Bark 密钥操作会分别报告操作结果与状态刷新结果，避免操作成功却显示失败。
- 通知诊断记录刷新失败时保留旧记录并提供重试。
- 删除已保存桌宠前，显示名称并要求二次确认；可以取消。
- 包含上一轮尚未发布的设置交互修复：通知模板自动保存、桌宠防重复保存、键盘焦点恢复和设置加载重试。

## 实机测试

1. **macOS / Windows / Linux**：升级安装后，桌宠、托盘菜单及已有设置仍正常；桌宠可拖动。
2. **通知文案**：输入一句新文案后立即退出应用，重新启动并打开通知设置；文案仍在，随后显示已保存。切换中英文与事件后分别检查。
3. **Bark**：已有密钥和通知开关仍在；真实事件按原设置发送，诊断记录能显示结果。不要在反馈中发送密钥。
4. **桌宠**：点击删除自定义桌宠先出现名称确认；取消不删除，确认后只删除所选桌宠。保存新桌宠后重复点击不会创建副本。
5. **Windows / Linux**：重复启动应用、打开设置窗口、切换托盘选项均没有新增进程或失去焦点。

## English

This is a prerelease for device testing. Stable 1.0.2 remains current until validation is complete.

- Pending notification wording is journaled locally and restored after an abrupt exit, then removed after a confirmed save. Bark keys are never stored in this journal.
- Hook and Bark key actions report the action result separately from a later status-refresh failure.
- Diagnostic history retains its last result and offers Retry when refresh fails.
- Deleting a saved pet requires a named confirmation and can be cancelled.
- Includes the earlier unreleased settings fixes: automatic template saving, duplicate-pet prevention, keyboard-focus retention, and load retry.

Test upgrade and pet dragging on macOS, Windows, and Linux; restart immediately after editing notification wording; verify Bark settings and real events; cancel and confirm a pet deletion; and check repeated app launches on Windows/Linux. Please never include a Bark key in feedback.
