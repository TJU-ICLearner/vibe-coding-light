# Vibe Coding Light 1.0.1

桌宠设置页的状态预览与交互修正。

- “按状态”模式下，点击状态选项卡会立即预览当前选择的布布、一二或已保存自定义桌宠对应的图片或 GIF；未设置专属素材时使用默认素材。新草稿也遵循同一切换规则。
- 单图模式保留状态预览菜单，切换制作模式时尽量保留当前预览状态。
- 明确标出正在预览当前桌宠还是新草稿；调整草稿的大小、动效、处理方式时自动切回草稿预览，状态提示同步更新。
- 修复快速切换桌宠、初始加载与删除当前桌宠时可能出现的预览不同步；保存期间禁用切换和删除操作。
- 优化窄窗口下的预览区布局。中英文说明已同步更新。

安装说明请参阅 [中文 README](../../README_CN.md) / [English README](../../README.md)。安装包的 SHA256 校验值见本页 `SHA256SUMS.txt`。
