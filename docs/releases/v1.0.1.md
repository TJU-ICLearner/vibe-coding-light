# Vibe Coding Light v1.0.1

本版将应用图标和 README 标志更新为用户选定的 3 号「终端光束」设计；5 号「猫咪编辑器」高清图保留在源码的 `assets/icon-concepts/` 中，可供之后切换。应用功能与 v1.0.0 相同。

适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”。安装包未经过 Apple 开发者签名和公证；若被 macOS 阻止打开，请在 Finder 中右键点击应用并选择“打开”。

安装包的 SHA-256 摘要见同页的 `SHA256SUMS.txt`。Intel Mac 暂无预编译安装包。
