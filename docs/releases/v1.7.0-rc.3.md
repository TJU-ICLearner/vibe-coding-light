# Vibe Coding Light v1.7.0 RC3

修复 Codex 额度提醒未触发的问题。此前额度轮询只查找常见命令行路径中的 `codex`；在仅安装 ChatGPT 桌面 App、且旧命令行链接失效的 Mac 上，应用无法找到内置 Codex 程序，因此不会读取额度，也不会产生 Bark 额度通知。现在额外支持系统或用户“应用程序”中的 ChatGPT App 内置 Codex。

请在通知设置中确认 Codex 下方显示“额度可读取”。额度提醒在剩余额度穿过已开启的 80%、50%、20%、0% 档位时发送，按周期分别提醒；首次读取作为基线，不补发安装前已经发生的档位变化。Bark 测试通知和任务完成通知仍可分别验证发送通道。

安装包为 Apple Silicon 版 ad-hoc 签名测试包，未经过 Apple Developer ID 公证。
