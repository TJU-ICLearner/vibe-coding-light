# Vibe Coding Light v1.6.0 RC3

修复 RC2 中桌宠点击有效、拖动却完全不动的问题。拖动期间的鼠标移动现在会合并处理，并在松开鼠标后完成已发生的最后一次位移；初次读取窗口位置较慢时，短距离拖动也不会被直接丢弃。RC2 的 macOS 原生全屏置顶支持保持不变。

请在 macOS 上验证：

1. 在普通桌面上单击桌宠，确认“摸摸”效果仍可触发；按住左键拖动，确认桌宠能跟随并停在松开的位置。
2. 分别试快速短拖、缓慢长拖；若有双屏，试着把桌宠拖到另一块屏幕。
3. 用应用窗口的绿色按钮进入 macOS 原生全屏空间，确认桌宠仍可见且可以拖动；再退出全屏确认位置正常。

安装包为 Apple Silicon 版 ad-hoc 签名测试包，尚未经过 Apple 公证。实际拖动交互需要在桌面上验证；自动化测试覆盖了高频移动、松开时仍有位置请求、初始化未完成时短拖等时序。
