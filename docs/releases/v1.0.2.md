# Vibe Coding Light 1.0.2

本版修复菜单栏、通知设置和桌宠设置中的异步交互问题。

- 菜单栏不会再用过期轮询结果覆盖刚完成的开关操作；慢轮询不会相互叠加。
- 桌宠隐藏时，菜单栏弹窗和原生菜单会禁用“摸摸”。
- 通知设置刷新或切换语言时保留正在输入的 Bark 密钥；较新的语言与状态事件不会被初始读取覆盖。
- 通知开关保存失败时恢复到已保存状态，并在设置区提示错误。
- 切换桌宠期间禁用“保存并使用”，避免保存结果与选中桌宠不一致。
- 桌宠启动时先订阅状态变化，避免初始加载期间漏掉新状态。
