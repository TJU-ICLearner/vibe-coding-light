# Vibe Coding Light v1.4.0

本版将「布布整套」的五张原始透明 GIF 设为内置桌宠：休息时睡觉、工作时在电脑前忙碌、等待时喝奶茶、出错时道歉、完成时跳舞。GIF 保持原有帧动画和画面文字，不叠加静态图片动效。默认桌宠按 1.5 倍显示，窗口为 208 × 208。

新安装默认显示布布。升级后，已选择的自定义桌宠继续保持选中；在桌宠设置中可随时选择「默认布布」。原有内置桌宠的保存 ID 保持兼容，「摸摸」仍可用于布布。应用图标未更改。

工作、等待和出错的原始 GIF 自带中文字；选择英文界面时，这些画面文字仍会出现。界面菜单和设置页的文字依旧随语言选项切换。

适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”。安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证；首次启动如被 macOS 拦截，请参见 [中文安装说明](https://github.com/TJU-ICLearner/vibe-coding-light/blob/main/README_CN.md#macos-提示已损坏或无法打开)。Intel Mac 暂无预编译安装包。

请在另一台 Mac 上做以下原生检查：

1. 新安装时确认布布出现，切换休息、工作、等待、出错和完成状态，确认各 GIF 播放正确、画面完整。
2. 在设置页切换到自定义桌宠，再切回「默认布布」；重启应用后确认选择保持。
3. 对布布触发两次「摸摸」，确认手部动画结束后 GIF 继续播放。
4. 切换中英文，确认设置页标签变化，并注意原始 GIF 画面里的中文字保持不变。
