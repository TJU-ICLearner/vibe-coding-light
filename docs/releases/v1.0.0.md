# Vibe Coding Light 1.0.0

首个正式版，支持 macOS（Apple Silicon）、Windows（x64）和 Linux（amd64）。此前发布的版本均作为开发测试版保留。

## 功能

- 内置布布五状态桌宠；支持透明 PNG/GIF、自定义各状态素材、静态图动效和大小调节。
- Claude Code 与 Codex 的托盘状态、当前会话和 Hook 安装。
- 可选 Bark 通知：按来源及事件/额度档位设置，自定义中英文文案、免打扰和本地发送记录。
- 中英文界面、登录时启动及版本检查。
- 正式版通知设置页不提供测试按钮。

## 升级与平台说明

- 测试版的版本号曾高于 1.0.0，因此请手动下载并安装本正式版；旧版可能不会把 1.0.0 显示为更新。本地桌宠和通知设置沿用原数据目录。
- 自动去背景目前仅在 macOS 14 及以上提供；Windows/Linux 可以导入透明 PNG 或 GIF。
- macOS 安装包使用 ad-hoc 签名，未经过 Apple 公证；Windows 安装包尚未代码签名。
- Windows Hook 需要 Git for Windows（Git Bash 与 Perl）；Linux Hook 需要 Bash 与 Perl，Bark 密钥存储需要 Secret Service。
