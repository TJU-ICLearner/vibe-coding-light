# Vibe Coding Light 1.0.0

首个公开正式版，支持 macOS（Apple Silicon）、Windows（x64）和 Linux（amd64）。

## 主要功能

- 两套内置 GIF 桌宠“默认布布”和“默认一二”，均有休息、工作、等待、出错、完成五种状态；选择内置桌宠时可在设置页播放并切换预览。
- 可为各状态导入自定义图片或透明 GIF；静态图片可选轻量动效。macOS 14 及以上支持静态图自动去背景。
- Claude Code 与 Codex 的状态、会话和 Hook；Cursor、TRAE、Grok Build、DeepSeek Harness 的可选 Hook 接入。
- 可选 Bark 通知，支持按来源、事件与额度档位设置，自定义标题和正文、免打扰与发送诊断。
- 中英文界面、外观主题、登录时启动及版本检查。正式版不显示模拟通知测试按钮。

## 安装说明

三平台安装方法、Hook 与 Bark 设置请参阅 [中文说明](../../README_CN.md) 或 [English guide](../../README.md)。安装包的 SHA256 校验值见本页 `SHA256SUMS.txt`。

macOS 安装包使用 ad-hoc 签名，尚未经过 Apple 公证；Windows 安装包尚未代码签名。
