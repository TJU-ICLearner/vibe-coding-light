# Vibe Coding Light v1.0.0

首个可下载测试版，适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载下方 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”即可安装。Intel Mac 暂无预编译安装包。

## 本版内容

- 托盘状态灯继续显示 Claude Code 和 Codex 的工作、等待、错误与完成状态。
- 保留默认像素猫；也可导入自己的 PNG 或 JPEG，预览并保存为桌宠。macOS 14+ 在本机自动去背景；macOS 12–13 可导入已有透明背景的 PNG。
- 自定义桌宠可调整尺寸和位置，并根据 Agent 状态播放轻量动效。设置窗口可切换、删除桌宠或恢复默认像素猫。
- 应用显示名称更改为 **Vibe Coding Light**；保留原有应用标识和钩子数据目录，以兼容已有本地设置。

## 测试提示

安装包未经过 Apple 开发者签名和公证。若 macOS 阻止打开，可在 Finder 中右键点击应用并选择“打开”。如仍提示已损坏，可运行：

```bash
xattr -cr "/Applications/Vibe Coding Light.app"
```

自动去背景、状态切换和本地持久化已在 Apple Silicon macOS 26.6.2 上测试；macOS 12–13 尚未实机验证。安装包的 SHA-256 摘要见同页的 `SHA256SUMS.txt`。
