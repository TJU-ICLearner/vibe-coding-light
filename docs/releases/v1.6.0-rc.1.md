# Vibe Coding Light v1.6.0 RC1

此测试版支持按事件自定义 Bark 通知的标题和正文。权限、提问、完成、错误、四个额度档位以及额度恢复分别有模板；中文和英文分别保存。设置页可预览变量替换后的示例通知，清空字段即可回到默认文案。

“包含详细内容”默认关闭。关闭时通知事件文件不记录任务、命令、错误或回复原文，推送也不含这些内容；打开后可用 `{task}`、`{command}`、`{error}`、`{reply}`、`{question}` 和 `{detail}` 插入原文。默认文案会附上与事件相关的原文，每项最多取前 1000 字。任务或工具输出可能含私人信息或密钥，开启后会发往 Bark 官方服务器。`{source}`、`{period}` 和 `{remaining}` 始终可用。

请在 macOS 上重点测试：

1. 升级安装后确认 Bark 密钥和原有通知开关仍在，“包含详细内容”保持关闭；旧的简短通知继续可用。
2. 为“权限待批准”修改标题和正文并放入 `{command}`；打开详细内容后，从 Codex 触发真正的权限请求，确认手机收到自定义文案和命令。
3. 关闭详细内容后再次触发权限请求，确认手机不再显示命令。
4. 分别测试 Claude Code 的权限、错误、完成通知，以及中英文切换后的模板；某些 Hook 不提供具体字段时，相应变量会留空。

此版仍使用 ad-hoc 签名，尚未经过 Apple 公证。Bark 先通知 iPhone；Apple Watch 是否显示由系统通知路由决定。
