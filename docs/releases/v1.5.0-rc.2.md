# Vibe Coding Light v1.5.0 RC2

这是用于排查 Bark 测试通知的 macOS 预发布版。测试按钮旁现在会立即显示“正在发送”，随后显示 Bark 已接受请求或具体的失败类型；按钮不可用时会提示先开启总开关并保存设备密钥。原先的结果显示在整页底部，容易在较小窗口中漏看。

安装后在“通知设置”中开启“手表通知”，确认显示“已保存到 macOS 钥匙串”，再点击“发送测试通知”。当前连接 Bark 公共服务 `api.day.app`；自建 Bark 服务器的密钥不能在这里使用。请留意按钮旁的结果：

- “已提交给 Bark”：Mac 到 Bark 的请求已被接受；若手机仍未显示，请对比 Bark App 自带的测试推送和通知记录。
- “Bark 拒绝”：请核对保存的是设备密钥本身，而不是完整测试链接。
- “无法连接 Bark”：请检查 Mac 网络。
- “未收到 Bark 的确认”：请先查看手机和 Bark 通知记录，再决定是否重试。

适用于 Apple Silicon Mac（macOS 12 或更新版本）。安装包使用 ad-hoc 签名，未经过 Apple Developer ID 公证；请参照 README_CN.md 中的 macOS 安装说明。此版不改变通知事件、桌宠素材或现有设置。
