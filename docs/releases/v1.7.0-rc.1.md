# Vibe Coding Light v1.7.0 RC1

本版按顺序加入四项可选改进：

1. **通知发送记录**：在通知设置中查看最近 100 条发送、跳过或失败结果及简短原因，可随时清空。记录仅包含来源、事件类型、时间和结果，不保存 Bark 密钥或任务、命令、错误原文。
2. **免打扰时段**：默认关闭。开启后默认在 Mac 本地时间 22:00–08:00 静音；权限确认、提问和错误默认放行，所有类别均可单独调整。静音通知不会补发，测试通知不受影响。
3. **当前会话菜单**：菜单栏显示最多 8 个近期 Claude/Codex 会话的来源、项目、状态和最近活动时间，不展示原文内容。
4. **登录启动与版本提醒**：登录启动和每天检查新版本均默认关闭；可手动检查。发现新版本时打开官方 GitHub 发布页，不会自动安装。登录启动使用 macOS 13+ 的系统登录项，可能需要在系统设置批准。

建议在 Mac 上测试：通知设置中的发送记录与免打扰跨午夜规则；同时运行 Claude/Codex 时当前会话菜单的变化；手动检查版本；开启登录启动后在系统设置中确认状态，再重启登录验证。Bark 的常规通知和桌宠拖动应保持正常。

安装包为 Apple Silicon 版 ad-hoc 签名测试包，未经过 Apple Developer ID 公证。
