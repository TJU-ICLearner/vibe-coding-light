# Vibe Coding Light v1.5.0 RC1

这是供 macOS 实机测试的预发布版。新增可选 Bark 通知：可按 Claude Code / Codex 分别启用权限确认、提问、完成、错误，以及剩余 80%、50%、20%、0% 和恢复提醒；额度通知分别标明来源与周期。默认关闭，不输入 Bark 密钥或不开总开关时不会发送通知。通知不含提示词、项目路径、命令或错误原文。

设置页支持中文和英文。旧版已安装的 Hook 会在启动时升级；原有桌宠和自定义素材仍保留。Claude 状态栏已有命令时，额度读取会保留原显示和显示设置。

适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”。本包使用 ad-hoc 签名，**没有 Apple Developer ID 公证**；若 macOS 阻止打开，请按 [中文安装说明](https://github.com/TJU-ICLearner/vibe-coding-light/blob/main/README_CN.md#macos-提示已损坏或无法打开) 核对校验和并处理。Intel Mac 暂无预编译安装包。

此版本已通过自动测试和本机打包、签名校验；Bark → iPhone → Apple Watch 路由以及钥匙串授权弹窗仍需实机检查。请按 [检查清单](https://github.com/TJU-ICLearner/vibe-coding-light/blob/codex/watch-notifications-impl/docs/superpowers/qa/2026-10-23-watch-notifications.md) 测试。
