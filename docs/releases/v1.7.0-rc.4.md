# Vibe Coding Light v1.7.0 RC4

通知设置页新增仅限 RC 版本使用的 Bark 全事件测试台。权限待批准、问题待回答、本轮回复完成、执行错误、额度剩余 80%／50%／20%／0% 和额度恢复各有独立“测试”按钮。可以选择 Claude Code 或 Codex；额度事件还可选 5 小时或 7 天周期。

模拟通知沿用当前总开关、来源与事件开关、免打扰和自定义文案。按钮旁会显示已提交、跳过原因或发送失败原因；诊断记录会标记为模拟测试。推送标题带“[测试]”或“[TEST]”，正文只使用虚构样例，不读取真实任务内容。模拟测试不会改动真实额度、会话或去重记录。

测试台验证通知规则、文案和 Bark 发送。真实额度能否读取仍请查看通知设置中的“额度可读取”；额度跨档触发需要真实运行观察。

安装包为 Apple Silicon 版 ad-hoc 签名测试包，未经过 Apple Developer ID 公证。正式版发布前会移除测试台及模拟发送命令。
