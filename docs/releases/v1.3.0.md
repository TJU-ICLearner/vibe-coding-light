# Vibe Coding Light v1.3.0

这版把菜单中的“鞭策”改为“摸摸”：点击菜单或按 ⌘B，手部动画会轻拍桌宠两次，适用于默认像素猫、静态图片和透明 GIF。切换桌宠或连续触发时会重置动画，不会留下旧特效。

每张静态图片现在可单独设置动效：跟随状态、静止、左右摇摆、上下浮动、呼吸、弹跳、轻微晃动。单图模式只需设置一张；按状态模式中未上传素材的位置会沿用默认图片及动效。GIF 仍只播放自身逐帧动画，不叠加这些动效。

新桌宠支持 **0.5–3 倍**大小，窗口会随图片放大并尽量保持在当前显示器的可用区域。设置页预览会缩放展示完整窗口并标注实际尺寸，已移除水平和垂直偏移输入。旧版已保存的桌宠及原有偏移仍可读取。

适用于 **Apple Silicon Mac（macOS 12 或更新版本）**。下载 DMG，将 `Vibe Coding Light.app` 拖入“应用程序”。安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证；首次启动如被 macOS 拦截，请参见 [中文安装说明](https://github.com/TJU-ICLearner/vibe-coding-light/blob/main/README_CN.md#macos-提示已损坏或无法打开)。Intel Mac 暂无预编译安装包。

请在另一台 Mac 上做以下原生检查：

1. 用默认猫和一张静态图分别触发“摸摸”，连续点击两次后确认手部动画结束且状态正常。
2. 将静态图调到 3 倍，确认桌宠显示完整，并把窗口拖到屏幕边缘后切换大小。
3. 给两种状态的静态图选不同动效，切换中英文、状态与单图／按状态模式后确认选择保留；透明 GIF 应继续播放原动画且动效选择不可用。
4. 如有旧版桌宠，确认可选用、显示及删除。
