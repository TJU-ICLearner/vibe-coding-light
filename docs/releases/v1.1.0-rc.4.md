# Vibe Coding Light 1.1.0 RC4

测试版，修复 Codex 待回答问题被误报为任务完成的问题，并调整 Hook 入口与通知设置排版。

- Codex 的当前轮次若以带选项的结构化问题结束，桌宠进入“等待”，Bark 发送“问题待回答”；不会再发送“本轮回复完成”。通知详细内容开启时，提醒中包含问题原文。普通文本提问仍可能无法识别。
- macOS 菜单栏“快捷控制”把 Cursor、TRAE（中国版）、Grok Build、DeepSeek Harness 的 Hook 入口移到会话列表前面，打开弹窗就更容易看到。
- 通知设置页的来源开关、状态和操作按钮使用固定列；工作事件与额度设置在宽窗口并排显示，窗口较窄时自动堆叠。

安装前请彻底退出旧版本。安装新版后重新执行一次“设置 Codex Hook”，再重启 Codex 会话，以确保正在使用新版脚本。若你开启了 Bark 的“问题待回答”，可用带选项的 Codex 提问验证；诊断记录应显示 question，而不是 completed。

macOS 安装包采用 ad-hoc 签名，尚未 Apple 公证。Windows 安装包未代码签名。请用同页 SHA256SUMS.txt 核对下载文件。
