# App icon concepts

The numbered contact sheet is read left to right, top to bottom.

- `option-03-terminal-beam.png`: selected for Vibe Coding Light v1.0.1. The installed app icon and root `logo.png` are generated from this source.
- `option-05-cat-editor.png`: standalone alternative retained for future selection.
- `options-01-09.png`: original comparison sheet.

The macOS `.icns` and Windows `.ico` files were generated with `pnpm tauri icon` from option 3. Other PNG icon sizes were resized from the same source.
