# BoardUI component source

The files in `boardui/` were installed using BoardUI CLI version **0.5.9** with the free registry items `button`, `tabs`, `segmented-control`, `file-upload`, `select`, `input`, `number-field`, `modal`, `switch`, and `textarea`, including their internal dependencies. Later pages may add more free items using the same pinned CLI version.

Upstream: [BoardUI](https://www.boardui.com/getting-started), [component documentation](https://www.boardui.com/components). The upstream documentation states that free components and the token system are MIT licensed. This repository keeps the generated source editable and records its origin here.

BoardUI styles are imported only by the settings, notifications, and quick-control windows. The transparent desktop-pet window does not load them.
